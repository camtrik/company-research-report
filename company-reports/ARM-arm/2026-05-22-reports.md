# ARM - Arm Holdings 研究报告

日期：2026-05-22

数据时间：行情、估值倍数、分析师目标价和同业数据于 2026-05-22 JST 检查；最新 regular-session 股价使用 2026-05-21 美股收盘价。

## 核心结论

Arm Holdings（`ARM`）是全球最重要的处理器 IP 平台之一，核心商业模式是授权 Arm 指令集、CPU/GPU/NPU/互联等 IP，并按客户芯片出货收取 royalty。过去它主要被市场视为移动端 IP 公司；2026 年以来，投资者开始把它重新定价为 AI data center CPU、hyperscaler custom silicon 和 agentic AI infrastructure 的 royalty layer。

截至 2026-05-21 收盘，`ARM` 股价为 `$298.23`，市值约 `$317.3B`，企业价值约 `$314.1B`。5 月 20 日上涨 `15.0%`，5 月 21 日再涨 `16.2%`，两日累计约 `33.7%`。直接催化是 NVIDIA Vera / Rubin CPU 叙事、NVIDIA 超预期财报、Jefferies / Bernstein / RBC 等 sell-side 上调目标价，以及 ARM 自身 FY2026 Q4 强劲财报共同形成的动量重估。

我的判断：ARM 是高质量资产，但当前价格已经在交易非常乐观的长期剧本。保守现金流 DCF 很难支持 `$298`；相对估值只有在市场继续给予 45-55x FY2027E EV/Revenue、或约 90-110x FY2027E EPS 时才接近现价。结论为 **Watch / 不追涨**：持有者可以继续用趋势和基本面验证管理仓位；新资金需要等待回撤或更明确的 AGI CPU 收入兑现。

## 公司概要

ARM 总部位于 Cambridge, UK，上市证券为 Nasdaq ADR。公司不直接大规模制造芯片，而是设计和授权处理器架构、CPU 核、GPU、NPU、interconnect、compute subsystem 和相关软件生态。客户包括手机 SoC 厂商、车载芯片厂商、IoT/工业厂商、cloud hyperscalers、AI accelerator 厂商和数据中心系统供应链。

ARM 的收入分为两类：

| 收入类型 | 机制 | 投资含义 |
|---|---|---|
| License and other | 客户取得 IP / architecture / CSS / design access，通常受大额合同和 backlog 转换节奏影响 | 波动更大，但能领先反映客户采用 Arm 平台的意愿 |
| Royalty | 客户产品出货后，按芯片或系统价值的一定比例支付 | 质量更高、持续性更强，是长期复利的核心 |

护城河的本质是生态和兼容性：Arm 架构已经嵌入移动设备、车载、IoT、嵌入式、PC 和云端 CPU 生态，开发者、操作系统、编译器、EDA、IP、Foundry 和系统厂商共同形成平台网络效应。最新变化是 ARM 不再只授权 IP，而是在 compute subsystem、Armv9、Neoverse CSS 和 AGI CPU 方向上向更高价值层延伸。

## 业务模式

ARM 的业务可以拆成四层：

| 层级 | 内容 | 投资含义 |
|---|---|---|
| Architecture | Arm instruction set / Armv9 等架构授权 | 最底层标准，客户粘性高，但 royalty rate 取决于合同结构 |
| IP cores | Cortex、Neoverse、Mali、Ethos 等 CPU/GPU/NPU/IP | 传统主业，覆盖移动、车载、IoT、数据中心 |
| CSS / platform | Neoverse CSS、compute subsystem、预集成平台 | 提升客户采用速度和 ASP，有助于提高 royalty dollars per chip |
| Silicon / AGI CPU | ARM 自身推出面向 agentic AI 的 production silicon | 新增长向量，但也可能改变原有轻资产模型和客户关系 |

当前最重要的投资问题是：数据中心 CPU 是否会把 ARM 从“手机 IP 平台”升级为“AI compute orchestration 的基础 royalty layer”。如果答案是肯定的，当前估值可以部分解释；如果 AGI CPU / Vera / Graviton / Axion 等需求低于预期，ARM 的估值回撤空间会很大。

## 连续两天暴涨原因

这次两日暴涨可以拆成四个层次：

1. **基本面底座**：ARM 刚交出 FY2026 Q4 record revenue，收入同比 `+20%`，license 收入同比 `+29%`，并强调数据中心 royalty、Armv9、CSS 和 hyperscaler adoption。
2. **CPU renaissance 叙事**：agentic AI 不只需要 GPU，也需要大量 CPU 做 orchestration、data movement、memory、security 和 workload coordination。ARM 在 shareholder letter 中称，agentic AI scaling 可能让数据中心每 GW 需要超过当前 `4x` 的 CPU capacity，并形成 2030 年超过 `$100B` 的市场机会。
3. **NVIDIA Vera / Rubin 催化**：NVIDIA Rubin 平台包含 Vera CPU，Vera 具备 full Armv9.2 compatibility；NVIDIA Q1 FY2027 财报又显示 AI data center 需求继续超预期，市场把 Vera/Rubin 出货映射为 ARM royalty upside。
4. **Sell-side 目标价集体上调**：Bernstein Outperform / `$300`、Jefferies Buy / `$290`、RBC 上调至 `$260` 等，使资金开始提前交易 FY2027-FY2031 的 AGI CPU upside。

需要强调：股价上涨不是因为 ARM 的 FY2026 EPS 突然能支撑 168x non-GAAP P/E，而是市场把长期 AI CPU TAM、数据中心 royalty 和 ARM 自研 AGI CPU 的期权一次性折现进股价。

## 竞争与护城河

**护城河来源：**

- **生态标准**：操作系统、编译器、软件、EDA、IP、foundry、开发者生态已经围绕 Arm 架构形成长期兼容性优势。
- **能效优势**：移动时代积累的低功耗设计能力，在数据中心和 AI inference / orchestration 里更有价值。
- **Royalty 复利模型**：一旦客户采用 Arm 架构，后续出货会带来多年 royalty；Armv9 / CSS / Neoverse 可提高每颗芯片 royalty dollars。
- **客户广度**：AWS Graviton、Google Axion、Microsoft Cobalt、NVIDIA Vera、Qualcomm、MediaTek、Apple ecosystem 等客户/生态提高了平台冗余度。
- **AI compute position**：如果 agentic AI 需要更多 CPU coordination，ARM 可受益于每个 AI rack / hyperscaler cluster 中 CPU 数量和价值量提升。

## 估值分析

### 方法一：DCF

保守现金流 DCF 使用以下基准假设：

| 假设 | 基准值 |
|---|---:|
| FY2026 revenue | `$4.92B` |
| 未来 5 年收入增长 | `25% / 25% / 23% / 20% / 17%` |
| FCF margin | `18% -> 30%` |
| WACC | `10.5%` |
| Terminal growth | `3.0%` |
| 净现金 | `~$3.2B` |

这个模型的纯 Gordon terminal DCF 约为 **`$45/股`**。即使用更偏市场化的 exit multiple 框架，例如 5 年后给 `40x` EBITDA，并与 Gordon terminal 取中值，DCF 也大约只有 **`$90-$100/股`**，且终值占比超过 `90%`。这说明 DCF 对 ARM 现价的解释力较弱，现价更多来自远期 TAM 和估值倍数，而非可见现金流。

### 方法三：SOTP

不做硬 SOTP。ARM 没有按业务线披露可用于估值的分部收入和利润，而且 IP、CSS、royalty 和 silicon 是同一架构生态的不同商业化层级。强行拆分会制造虚假的精确性。

### 估值结论

| 情景 | 合理价值区间 | 触发条件 |
|---|---:|---|
| Bear | `$80-$120` | 手机/消费电子 royalty 放缓，AGI CPU 只贡献有限收入，SBC 继续高企，估值向成熟半导体/EDA 收敛 |
| Base | `$170-$230` | 收入维持 `20-25%` 增长，数据中心 royalty 成为第二曲线，市场给予 `30-40x` FY2027E EV/Revenue |
| Bull | `$270-$330` | ARM 成为 AI CPU / agentic compute 的核心 royalty layer，NVIDIA Vera、AWS Graviton、Google Axion、Microsoft Cobalt 和 AGI CPU 持续放量，市场愿意维持 `45-55x` FY2027E EV/Revenue |

当前 `$298.23` 已经落在 bull case 区间内。对长期持有者，核心问题是是否相信 ARM 的数据中心 CPU / AGI CPU 收入在未来 3-5 年会非线性放大；对新资金，当前缺乏足够安全边际。

## 催化剂 / 关注点

**短期（< 6 月）：**

- Q1 FY2027 财报：收入是否超过 `$1.26B +/- $50M` 指引，non-GAAP EPS 是否超过 `$0.40 +/- $0.04`。
- NVIDIA Vera / Rubin 订单可见度：是否继续披露 CPU revenue、Vera standalone shipments、Vera Rubin rack-scale adoption。
- Sell-side EPS / revenue revision：目标价已经上调，关键是 consensus 是否真的把 FY2028-FY2031 收入上修。
- SoftBank 持股/流通盘：大股东结构和可交易流通盘会放大股价波动。
- 监管/授权模式：FTC 或其他监管机构若调查 IP 授权方式，可能压低估值倍数。

**中期（6-18 月）：**

- Data center royalty 是否连续多个季度加速，并能抵消 smartphone royalty 波动。
- Armv9 / CSS 是否继续提高 royalty rate per chip。
- AGI CPU 是否从新闻稿进入实际收入确认，且不显著侵蚀公司轻资产利润率。
- Hyperscaler custom silicon 是否持续转向 Arm，而非 x86 反攻或 RISC-V 替代。
- SBC 占收入是否从 FY2026 的 `21%+` 下降。

## 风险 / 反向论证

1. **估值前置过多**：当前约 `64x` FY2026 revenue 和 `168x` FY2026 non-GAAP EPS，已经折现了多年高增长和高倍数，任何下修都可能导致大幅回撤。
2. **AGI CPU 收入不确定**：ARM 自研 silicon 是新方向，可能带来更高收入，但也可能带来更高研发/供应链/客户冲突风险，削弱原有轻资产 IP 模型。
3. **Royalty rate 与出货量不透明**：NVIDIA Vera 或 hyperscaler CPU 的总销售额不等于 ARM 收入，关键取决于 royalty rate、合同结构和确认节奏。
4. **SBC 稀释**：FY2026 SBC `$1.052B`，占收入 `21.4%`。如果把 SBC 当真实成本，现金流质量比 non-GAAP 利润看起来弱。
5. **智能手机仍是重要基础盘**：若高端手机换机、Android SoC 或中国智能手机链条疲软，可能拖累 royalty growth。
6. **客户集中与生态冲突**：Apple、Qualcomm、NVIDIA、hyperscalers 都有强议价能力；ARM 若向 silicon 延伸，可能改变与部分 licensees 的关系。
7. **SoftBank 控制权风险**：SoftBank 仍是重要控股股东，其资本配置和潜在减持会影响少数股东风险收益。

**什么情况下我会撤回 Watch 结论？**

如果未来两个季度数据中心 royalty 没有明显加速，Q1/Q2 FY2027 指引或实际收入低于预期，且 FY2028 AGI CPU / Vera / hyperscaler CPU 相关收入没有被 consensus 实质性上修，我会把观点从 `Watch` 下调到 `Pass`，并把合理价值中枢下调到 `$120-$170`。

## 后续关键问题

1. NVIDIA Vera CPU 对 ARM 的实际 royalty rate 是多少？是接近传统 Neoverse / Grace，还是更低？
2. ARM AGI CPU FY2028-FY2031 的收入路径是否能从订单/设计赢得转化为确认收入？
3. 数据中心 royalty 是否能持续达到或超过 `20%` 增长，而不是单季叙事？
4. FY2027 license revenue 是否会因为 Q4 FY2026 高基数而出现波动？
5. SBC 占收入是否开始下降，还是继续稀释股东经济收益？
6. Hyperscaler custom silicon 是否持续采用 Arm，而不是转向自研 ISA、RISC-V 或重新提高 x86 份额？
7. 当前 sell-side 目标价上调后，未来 1-2 个季度是否还有 EPS / revenue estimate revision 支撑股价？
