## 核心结论

Arm Holdings（`ARM`）仍是全球最重要的处理器 IP 平台之一，商业模式以 architecture / IP / CSS 授权和 royalty 为核心。2026 年以来，市场不再只把 ARM 当作移动端 IP 公司，而是把它定价为 **AI data center CPU + Windows-on-Arm AI PC + agentic AI infrastructure** 的底层架构受益者。

我的研究观点从 2026-05-22 的 **Watch / 不追涨** 调整为 **Watch / 严格风控**。ARM 的长期战略地位继续增强，但 `$400+` 盘前价格已明显超过此前 bull case，隐含约 `87x` FY2026 EV/Revenue、约 `228x` FY2026 non-GAAP EPS。现在股价主要交易“架构大迁移 + NVIDIA 背书 + 低流通盘动量”，不是交易当期现金流。若持有，应把仓位管理和回撤承受能力放在第一位；若新开仓，当前没有安全边际。

## 公司概要

ARM 总部位于 Cambridge, UK，上市证券为 Nasdaq ADR。公司不直接大规模制造传统意义上的 merchant CPU，而是设计和授权处理器架构、CPU 核、GPU、NPU、interconnect、compute subsystem 和相关软件生态，并按客户芯片或系统出货收取 royalty。2026 年新变化是 ARM 通过 Arm AGI CPU 进入 production silicon，并试图在 AI data center CPU 中取得更高价值量。

ARM 的收入分为两类：

| 收入类型 | 机制 | 投资含义 |
|---|---|---|
| License and other | 客户取得 IP / architecture / CSS / design access，收入受大额合同和 backlog 转换节奏影响 | 波动更大，但能领先反映客户采用 Arm 平台的意愿 |
| Royalty | 客户产品出货后，按芯片或系统价值的一定比例支付 | 质量更高、持续性更强，是长期复利核心 |

护城河的本质是生态和兼容性。Arm 架构已经嵌入移动设备、车载、IoT、嵌入式、PC 和云端 CPU 生态，开发者、操作系统、编译器、EDA、IP、foundry 和系统厂商共同形成平台网络效应。最新催化来自 NVIDIA：Vera 强化数据中心 CPU，RTX Spark 强化 Windows-on-Arm PC。两者都在扩大“非手机 Arm 计算”的可想象空间。

## 业务模式

ARM 的商业化层级可以拆成四层：

| 层级 | 内容 | 投资含义 |
|---|---|---|
| Architecture | Arm instruction set / Armv9 等架构授权 | 最底层标准，客户粘性高，但 royalty rate 取决于合同结构 |
| IP cores | Cortex、Neoverse、Mali、Ethos 等 CPU/GPU/NPU/IP | 传统主业，覆盖移动、车载、IoT、数据中心 |
| CSS / platform | Neoverse CSS、compute subsystem、预集成平台 | 缩短客户设计周期，提高 ASP 和 royalty dollars per chip |
| Silicon / AGI CPU | ARM 自身推出面向 agentic AI 的 production silicon | 新增长向量，但会带来供应链、客户冲突和资本强度变化 |

6/1 的 NVIDIA 新闻对 ARM 有两层意义。第一，Vera CPU full production 让“AI agent 时代 CPU 重新重要”的论点更可信。第二，RTX Spark Windows AI PC 让市场开始交易“Windows PC 可能再度向 Arm 架构迁移”的期权。需要注意，NVIDIA 的 PC superchip 对 ARM 的收入贡献不会等同于 NVIDIA 或 PC OEM 的整机收入，最终仍取决于授权结构、royalty rate 和实际出货量。

## 本轮再次暴涨的原因

这次 6/1 盘前暴涨不是孤立事件，而是 5 月下旬以来 ARM 叙事连续升级后的第三段加速。

1. **NVIDIA Vera 进入 full production**：NVIDIA 表示 Vera 是为 AI agents 设计的 CPU，能提升 agentic AI、reinforcement learning、data processing 等工作负载。客户名单覆盖 AI labs、cloud、金融交易和系统厂商，强化了 ARM 在数据中心 CPU 的可见度。
2. **RTX Spark 把 ARM 带进 Windows AI PC 叙事**：NVIDIA 与 Microsoft 宣布的 RTX Spark PC 平台使用 Grace CPU，并由 MediaTek 参与 custom CPU design。市场把它理解为 Windows-on-Arm 终于获得 NVIDIA/Microsoft 双重背书。
3. **x86 / Qualcomm 被资金拿来做相对交易**：Reuters 报道 NVIDIA PC chip 后，AMD、Intel、Qualcomm 盘前承压。资金正在把“赢家”归到 ARM/NVIDIA/Microsoft，把“潜在份额被挤压者”归到传统 PC CPU 和既有 Windows-on-Arm 供应链。
4. **Sell-side 目标价持续上调**：Mizuho `$360` 目标价叠加 Bernstein、Jefferies 等前期看多报告，使动量资金不断上修 ARM 的可交易目标。
5. **低流通盘放大波动**：SoftBank 持股比例高，可交易 float 相对市值较小。高 beta、期权交易和 AI 半导体动量会把基本面新闻放大成价格跳跃。

核心判断：这轮上涨主要是 **架构迁移叙事 + NVIDIA 背书 + 盘前低流动性**。它提高了 ARM 长期 bull case 的可信度，但还没有直接证明 ARM 的 FY2027-FY2028 收入和 EPS 足以支撑 `$400+`。

## 竞争与护城河

**护城河来源：**

- **生态标准**：操作系统、编译器、软件、EDA、foundry、IP 和开发者生态围绕 Arm 架构形成长期兼容性优势。
- **能效优势**：移动端低功耗积累在 AI inference、data center orchestration、edge AI 和 AI PC 中更有价值。
- **Royalty 复利模型**：客户采用 Arm 架构后，后续出货可带来多年 royalty；Armv9 / CSS / Neoverse 可提高每颗芯片 royalty dollars。
- **客户广度**：AWS Graviton、Google Axion、Microsoft Cobalt、NVIDIA Vera、NVIDIA RTX Spark、Qualcomm、MediaTek、Apple ecosystem 等共同提高平台冗余度。
- **AI compute position**：如果 agentic AI 确实需要更多 CPU coordination，ARM 可同时受益于 data center、cloud custom silicon 和 AI PC。

**竞争与替代风险：**

- x86 不会自动消失。Intel / AMD 在服务器和 PC 生态仍有软件兼容、企业采购和性能路线图优势。
- Qualcomm 仍是 Windows-on-Arm 的既有核心供应商，NVIDIA 入局可能扩大 Windows-on-Arm，但也可能压缩 Qualcomm 而不是直接让 ARM capture 全部价值。
- RISC-V 在部分嵌入式、AI accelerator controller 和中国供应链中仍是长期替代风险。
- NVIDIA 自研 Olympus / Vera 强化 Arm ISA，但也可能提高 NVIDIA 自身议价能力，使 ARM capture 的价值低于市场想象。

## 估值分析

### 方法一：DCF

保守 DCF 仍不支持 `$400+`。沿用 2026-05-22 基准假设：FY2026 revenue `$4.92B`，未来五年收入增长 `25% / 25% / 23% / 20% / 17%`，FCF margin 从 `18%` 提升至 `30%`，WACC `10.5%`，terminal growth `3.0%`。纯 Gordon terminal DCF 约 `$45/股`；若五年后给 `40x EBITDA` 并与 Gordon terminal 取中值，也大约只有 `$90-$100/股`，且终值占比超过 `90%`。

DCF 的含义不是 ARM 只能值 `$100`，而是当前估值几乎完全取决于远期 TAM、terminal multiple 和 AI CPU/AI PC 收入路径，短期可见现金流无法独立解释现价。

### 方法二：相对估值

以 2026-06-01 盘前 `$403.99` 估算：

| 指标 | 隐含水平 |
|---|---:|
| 市值 | `~$431.5B` |
| EV | `~$428.3B` |
| EV / FY2026 Revenue | `~87.1x` |
| Price / FY2026 non-GAAP EPS | `~228.2x` |
| EV / FY2027E Revenue（假设 FY2027 revenue `$6.15B`） | `~69.6x` |
| Price / FY2027E EPS（假设 FY2027 EPS `$3.05`） | `~132.5x` |

反推当前价格需要什么假设：

| 估值锚 | 支撑 `$404` 需要的条件 |
|---|---|
| `50x` FY2027E EV/Revenue | FY2027 revenue 需要约 `$8.6B`，较 FY2026 增长约 `74%` |
| `40x` FY2027E EV/Revenue | FY2027 revenue 需要约 `$10.7B`，较 FY2026 增长约 `118%` |
| `100x` FY2027E P/E | FY2027 EPS 需要约 `$4.04` |
| `80x` FY2027E P/E | FY2027 EPS 需要约 `$5.05` |

这意味着 `$400+` 已不是普通 bull case，而是 **bull-plus / momentum case**：市场需要相信 NVIDIA Vera、RTX Spark、hyperscaler custom Arm CPUs 和 ARM AGI CPU 会在 FY2027-FY2031 形成快速、可见、且高利润率的收入曲线。

### 方法三：SOTP

仍不做硬 SOTP。ARM 没有按业务线披露可用于估值的分部收入和利润，且 IP、CSS、royalty、AGI CPU 和客户 CPU 是同一架构生态的不同商业化层级。强行拆分会制造虚假的精确性。

### 估值结论

| 情景 | 合理价值区间 | 触发条件 |
|---|---:|---|
| Bear | `$100-$150` | 手机/消费电子 royalty 放缓，AGI CPU 只贡献有限收入，SBC 继续高企，估值向成熟半导体/EDA 收敛 |
| Base | `$180-$260` | 收入维持 `20-30%` 增长，数据中心 royalty 成为第二曲线，市场给予 `30-45x` FY2027E EV/Revenue |
| Bull | `$300-$360` | Vera、Axion、Cobalt、Graviton、AGI CPU 均验证 Arm CPU 加速，市场愿意给予 `50-60x` FY2027E EV/Revenue 或 `100x+` FY2027E EPS |
| Bull-plus / Momentum | `$400+` | NVIDIA/Microsoft 把 Windows-on-Arm AI PC 变成主流品类，同时 ARM 在 data center CPU 和自研 AGI CPU 上兑现超预期收入；需要后续订单和上修验证 |

当前盘前 `$403.99` 已经进入 bull-plus / momentum 区间。结论不是“不能再涨”，而是上涨的驱动力已经从基本面验证转向叙事扩散和资金拥挤，回撤风险显著上升。

## 催化剂 / 关注点

**短期（< 6 月）：**

- 2026-06-01 美股开盘后的真实成交：盘前 `$400+` 是否能维持，还是开盘后回落。
- NVIDIA GTC Taipei / Computex 后续披露：RTX Spark 是否明确采用 Arm 授权结构，以及 OEM 机型、售价、出货节奏。
- Vera 订单和 revenue visibility：NVIDIA 是否给出 Vera standalone CPU revenue、Vera Rubin rack 出货、客户采购规模。
- Sell-side estimate revision：目标价上修不够，关键是 FY2027-FY2029 revenue / EPS 是否被实际上修。
- ARM Q1 FY2027 财报：收入是否超过 `$1.26B +/- $50M` 指引，non-GAAP EPS 是否超过 `$0.40 +/- $0.04`。

**中期（6-18 月）：**

- Data center royalty 是否连续多个季度加速，并能抵消 smartphone royalty 波动。
- Armv9 / CSS 是否持续提高 royalty rate per chip。
- RTX Spark 是否能让 Windows-on-Arm 变成真实出货品类，而不是小众高端 AI PC。
- ARM AGI CPU 是否从 `$2B demand` 转化为确认收入、毛利和 FCF。
- SBC 占收入是否从 FY2026 的 `21%+` 下降。

## 风险 / 反向论证

1. **估值极端前置**：盘前 `$403.99` 隐含约 `87x` FY2026 revenue 和 `228x` FY2026 non-GAAP EPS，任何收入或估值倍数下修都可能带来剧烈回撤。
2. **NVIDIA 新闻不等于 ARM 收入**：Vera 和 RTX Spark 强化 Arm 架构，但 ARM 能 capture 的价值取决于授权、royalty rate 和合同结构。
3. **AI PC 可能雷声大雨点小**：Windows-on-Arm 已经多次尝试，生态兼容、价格、续航、软件和消费者真实需求仍需验证。
4. **Vera 客户表述偏早期**：NVIDIA 公告中的 exploring / planning adoption 不是不可撤销采购合同。
5. **SBC 稀释**：FY2026 SBC `$1.052B`，占收入 `21.4%`。如果把 SBC 当真实成本，现金流质量明显低于 non-GAAP 利润。
6. **监管和授权模式风险**：FTC/反垄断审查、Qualcomm 纠纷、客户对 ARM 自研 silicon 的反应都可能压低估值倍数。
7. **低流通盘双刃剑**：SoftBank 控股导致 float 较小，上涨时放大动量，下跌时也可能放大流动性冲击。

**什么情况下我会撤回 Watch 结论？**

如果 ARM 股价在 `$400+` 附近维持，但未来两个季度数据中心 royalty 没有明显加速，RTX Spark / Vera 没有带来可量化 revenue revision，且 FY2027 指引仍只体现正常 20%-30% 增长，我会把观点从 `Watch` 下调到 `Pass`，并把合理价值中枢重新压回 `$180-$260`。
