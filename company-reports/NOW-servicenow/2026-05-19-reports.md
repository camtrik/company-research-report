# NOW - ServiceNow 研究报告

日期：2026-05-19

## 核心结论

ServiceNow（`NOW`）是一家高质量企业软件公司，核心价值不是单点 IT 工单工具，而是嵌入大型企业 IT、HR、客服、安全、风险、采购和低代码应用的 workflow execution layer。AI 时代它的机会在于把模型输出接到权限、审批、记录系统、工单、CMDB、业务规则和合规留痕里，成为企业 AI agent 的受控执行层。

截至 2026-05-18 收盘，`NOW` 股价为 `$103.42`，市值约 `$106.7B`，企业价值约 `$103.9B`。5 月 18 日单日上涨 `8.8%`，5 日涨幅约 `13.0%`。上涨主要来自市场情绪修复：BofA 以 `Buy / $130` 目标价重新覆盖，Experian 多年合作增强“trusted decisioning + agentic workflow”叙事，Knowledge 2026 后市场开始重新评估 ServiceNow 是 AI 受益者而非被 AI 替代者。

我的保守基准估值仍约 **`$97/股`**：DCF 约 `$90`，相对估值约 `$104`。最新情报提高了 bull case 的可信度，但还没有改变近期财务模型。当前股价已经高于我的保守点估值约 `7%`，进入 **Watch / 等 Q2 验证** 区域。若持有，不急于卖；若新开仓，可以考虑小比例观察仓，但不适合一次性追满，后续加仓应等待价格回撤给出安全边际，或等待 Q2 财报验证 organic growth 和 margin 路径。

## 公司概要

ServiceNow 总部位于 Santa Clara, California，行业为 enterprise application software。公司提供云端 AI workflow 平台，帮助企业把跨部门请求、审批、工单、资产、权限、客户服务、HR 服务、风险与合规流程数字化和自动化。

商业模式以 subscription revenue 为主。云服务通常在合同期内按 ratable basis 确认收入，客户合同一般为固定金额、通常不可取消。2025 年总收入为 `$13.278B`，其中绝大部分来自 subscription。ServiceNow 的核心指标不是单个产品的市场份额，而是平台是否持续扩展到更多 workflow、更多部门和更高价值的 AI/安全/数据治理场景。

Q1 2026 数据显示，订阅收入 `$3.671B`，同比增长 `22%`；总收入 `$3.770B`，同比增长 `22%`；cRPO 为 `$12.64B`，同比增长 `22.5%`；RPO 为 `$27.7B`，同比增长 `25%`。Now Assist 年合同价值超过 `$1M` 的客户同比增长超过 `130%`。这些指标说明 AI 并非纯口号，但还需要证明 AI 能带来持续 revenue acceleration，而不是只提升叙事估值。

## 业务模式

ServiceNow 的价值可以拆成三层：

| 层级 | 主要内容 | 投资含义 |
|---|---|---|
| 核心 workflow 系统 | ITSM、ITOM、ITAM、Security Operations、Integrated Risk Management、HR Service Delivery、Customer Service Management、Field Service、Source-to-Pay 等 | 嵌入流程、权限、数据模型和审计机制后迁移成本高 |
| 平台与低代码层 | App Engine、Automation Engine、Workflow Data Fabric、RaptorDB、Integration Hub、Creator / Developer tooling | 从应用套件升级为企业内部 workflow app 平台 |
| AI 执行与治理层 | Now Assist、AI Agents、Autonomous Workforce、AI Control Tower、Context Engine、Action Fabric、MCP Server、EmployeeWorks、Build Agent | 把 AI 输出转化为可授权、可审计、可治理的企业动作 |

最新产品叙事的重点是 **Action Fabric + AI Control Tower + Context Engine**。ServiceNow 试图把自己定位为“任何 AI agent 都可以调用的 system of action”：外部 agent 可以通过 MCP Server 触发 ServiceNow 里的流程、审批、playbooks 和业务规则；每次动作再经过 AI Control Tower 做身份验证、权限范围、审计、消耗计量和治理。

这个方向如果成功，会把 ServiceNow 从“企业应用软件”重新定价为“agentic enterprise 的运行时和治理层”。如果失败，风险是企业只把它视为昂贵的传统 workflow suite，AI 预算流向 Microsoft、Salesforce、Atlassian、Workday 或专门的 AI agent startup。

## 增长驱动

1. **核心平台继续扩张**：ServiceNow 从 ITSM 向 ITOM、SecOps、Risk、HR、CSM、Field Service、Procurement、Creator workflow 扩展，模块越多，切换成本越高。
2. **AI agent 治理需求上升**：企业部署 AI agent 后需要权限、审计、流程、合规和异常处理。ServiceNow 的 bull case 是成为 AI agent 的 system of action，而不是被 AI 抽象层绕过。
3. **Action Fabric 打开外部 agent 通道**：Claude、Copilot 或客户自建 agent 如果要执行企业动作，需要可审计的 workflow runtime。ServiceNow 通过 MCP Server 和 AI Control Tower 争夺这个入口。
4. **安全与身份能力补强**：Armis、Veza 和 Moveworks 分别补强资产安全、身份权限和企业搜索/对话入口，有助于把 ServiceNow 从 workflow 平台扩展成更完整的 AI execution and governance stack。
5. **数据层强化**：Context Engine、Workflow Data Fabric、RaptorDB Pro、Autonomous Data Analytics 和 Data Catalog 都指向同一问题：企业 AI 缺的不是模型，而是可信、实时、可治理的业务上下文。
6. **2030 长期目标**：公司在 2026 年 Financial Analyst Day 提出 2030 年 subscription revenue `$30B+` 目标，并预计 ServiceNow AI 到 2030 年占 ACV 超过 `30%`。这相当于从 2026 指引中点起维持约 high-teens 复合增长。

## 竞争与护城河

**护城河来源：**

- **流程迁移成本**：ServiceNow 一旦嵌入 IT、HR、客服、安全、采购和审批流，迁移不是替换 UI，而是重做流程、权限、数据模型、集成和审计机制。
- **企业 workflow 数据优势**：AI agent 要执行真实动作，需要知道资产关系、服务依赖、权限和业务规则。ServiceNow 处在这些数据和流程的交汇处。
- **多产品扩张**：客户使用的模块越多，平台粘性越强，且 cross-sell 可持续提高 ACV。
- **企业级治理能力**：安全、合规、权限、人审、审计日志和大型企业采购能力，是通用 AI agent startup 难以短期复制的部分。
- **系统集成生态**：大型项目通常需要 Accenture、Deloitte、KPMG、Infosys 等 SI 生态落地，生态投入进一步提高替换成本。

## 估值分析

### 方法一：SBC-adjusted DCF

基准模型把 SBC 视为真实经济成本。核心假设如下：

| 假设 | 基准值 |
|---|---:|
| FY2026 revenue | `$16.2B` |
| FY2027 revenue | `$19.2B` |
| FY2030 revenue | `$28.2B` |
| 2026-2030 revenue path | `22.0% -> 18.5% -> 16.0% -> 13.5% -> 11.5%` |
| Owner FCFF margin | `19.5% -> 24.5%` |
| WACC | `9.0%` |
| Terminal growth | `2.5%` |
| 净现金 | `~$2.75B` |

基准 DCF 约为 **`$90/股`**。这个结果低于公司口径 FCF 推导，因为模型没有把 SBC 完全视为免费融资。

### 方法二：相对估值

ServiceNow 当前约 `7.4x` TTM EV/Revenue。成熟应用软件同业大多在 `3x-6x` EV/Revenue；更高增长的基础设施/安全/数据类 SaaS 可以明显更高。考虑 NOW 增速高于成熟应用软件、但低于 hypergrowth SaaS，同时利润率和 FCF 质量强于多数高增长 SaaS，我仍采用约 `6.5x` FY2026E EV/Revenue 作为保守基准。

| 估值口径 | 核心假设 | 隐含价值 |
|---|---:|---:|
| EV / FY2026E Revenue | `6.5x` FY2026E revenue `$16.2B` | `~$105/股` |
| Forward P/E cross-check | `22x` FY2027E EPS `$5.03`，折现一年 | `~$101/股` |
| 相对估值基准 | EV/Revenue 为主，P/E 交叉验证 | `~$104/股` |

BofA 的 `$130` 目标价可以视为 bull-leaning market multiple：约 `19x` 2027E EV/FCF。这个目标不是不可能，但隐含条件是 AI Control Tower / Action Fabric / Autonomous Workforce 的商业化能提高 FCF 可见度，并且 Armis 带来的 2026 margin headwind 在 2027 年确实正常化。

### 方法三：SOTP

不做硬拆。ServiceNow 虽然有多条产品线，但并不按独立经营分部披露收入和利润，且经济实质是统一平台、统一客户关系和统一 go-to-market。把 ITSM、HR、CRM、安全和 AI 拆成多个独立资产套倍数，会制造虚假的精确性。

### 估值结论

| 情景 | 合理价值 | 核心假设 |
|---|---:|---|
| Bear | `$55-$70` | Organic growth 掉到 mid-teens 以下，AI 更多是防守而非增量，SBC / 并购继续压低现金流质量 |
| Base | `$90-$105` | FY2026 指引实现，Q2-Q3 organic cRPO 稳住，FY2027 margin normalization 逐步可见 |
| Bull | `$130-$150+` | 2030 `$30B+` subscription revenue 路径可信，AI ACV 持续超预期，SBC 占收入下降，市场重新给予 AI workflow platform 溢价 |

当前 `$103.42` 已接近基准区间上沿。结论从 5 月 17 日的“接近合理价值”更新为：**情绪修复后，股价略高于保守内在价值点位；继续持有可以，但新资金不宜按低位反弹逻辑追涨**。

### 入场与仓位判断

这次上涨具备趋势转好的早期特征：市场正在把 ServiceNow 从“可能被 AI 抽象层绕过的传统 SaaS”重新定价为“企业 AI agent 的执行和治理层”。BofA 重新覆盖、Experian 合作、Action Fabric / MCP Server、AI Control Tower 和 AWS 合作，都强化了这个方向。

但这仍属于叙事与情绪修复，尚未完成基本面确认。新资金更合适的处理方式是 **先建小比例观察仓**，用真实仓位跟踪 Q2 财报前后的信息变化；不适合在 5 月 18 日大涨后一次性重仓追入。后续加仓需要满足两个条件之一：一是股价回撤后估值重新进入更有安全边际的位置；二是 Q2 财报证明剔除 Armis 后 cRPO 仍稳、AI ACV 继续高增长、FY2027 margin normalization 可信。

- FY2027 margin normalization 是否兑现。
- AI ACV 是否能向 2030 年超过 30% ACV 的目标推进。
- Subscription revenue growth 能否在不靠大额并购的情况下维持 high-teens 到 20%。
- SBC 占收入是否开始下降，回购是否只是抵消稀释，还是能够真正提升每股价值。
- Action Fabric 是否能成为外部 AI agents 的默认企业执行层，而不是一个只在 ServiceNow 客户内部使用的功能。

## 风险 / 反向论证

1. **Organic growth 低于 headline**：如果剔除 Armis 后 cRPO/订阅收入持续放缓，`7.4x` EV/Revenue 仍可能被压到 `5x` 或更低。
2. **SBC 和稀释**：FY2025 SBC 为 `$1.955B`，Q1 2026 SBC 为 `$547M`。公司回购能管理稀释，但若用股东真实经济成本衡量，FCF 质量要打折。
3. **AI pricing 未证明**：Action Fabric 和 AI Control Tower 的产品方向清晰，但客户最终如何为 agent execution、governance、consumption 付费还需要验证。
4. **AI 竞争改变定价**：Microsoft、Salesforce、Oracle、SAP、Workday、Atlassian，以及 AI agent 初创公司都在争夺企业工作流入口。ServiceNow 必须证明 agentic workflow 是增量，而不是被 AI 抽象层绕过。
5. **并购整合风险**：Armis、Veza、Moveworks 分别进入资产安全、身份权限和企业搜索 / 对话入口，战略上相关，但整合复杂，短期 margin headwind 已经明确。
6. **大型企业销售周期和地缘风险**：Q1 2026 订阅收入增长受到中东大型 on-prem deal 延迟约 75 bps 拖累；大型交易集中在季度末，容易造成 cRPO 波动。

**什么情况下我会撤回结论？**

如果未来两个季度剔除并购后的 cRPO constant currency growth 低于 mid-teens，且管理层不能给出 FY2027 margin 反弹的清晰路径，我会把观点从 `Watch` 下调到 `Pass`，估值中枢下调到 `$70-$85`。

- **回购**：Q1 2026 公司回购约 20.1M 股，其中包括此前 `$2B` ASR 的 18.5M 股，以及公开市场回购 1.6M 股、金额 `$225M`。截至 Q1 末，回购授权剩余约 `$4.2B`。
