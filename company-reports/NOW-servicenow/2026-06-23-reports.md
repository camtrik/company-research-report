# NOW - ServiceNow 研究报告

日期：2026-06-23

数据时间：行情、估值倍数、分析师预期和同业数据于 2026-06-23 JST 检查；最新 regular-session 股价使用 2026-06-22 美股收盘价。

## 核心结论

ServiceNow（`NOW`）从 5 月底的 `$124.37` 回落到 2026-06-22 收盘的 `$93.01`，投资问题重新从“是否追高”变成“回落后是否有足够安全边际”。我的基准合理价值约为 **`$105/股`**，相对当前价格约有 `+13%` 上行；但如果把 SBC 全额视为普通股东真实成本，价值约为 **`$82/股`**。因此结论是：**高质量公司回到可分批参与区间，但不是无脑低估。**

业务层面，ServiceNow 仍是企业 AI execution / governance layer 的真实候选者。Q1 2026 财报显示订阅收入、RPO/cRPO、现金流和 Now Assist 大客户数据都没有崩坏；Action Fabric、MCP Server、AI Control Tower 和 Context Engine 也强化了“AI agent 需要受治理执行层”的产品逻辑。问题在于市场现在要求更明确的验证：AI 到底是净新增收入，还是主要保护传统 seat-based SaaS；剔除 Armis 后 organic cRPO 是否仍稳定；SBC 占收入能否下降。

当前位置 `$93.01` 已明显低于我 5 月 31 日折中基准区间 `$115-$130`，也低于当前相对估值和部分 SBC-adjusted DCF 的中枢。投资上可以把 `$90-$95` 作为小到中等仓位的分批区间；如果 Q2 证明 organic cRPO、AI ACV 和 FY2027 margin normalization 都能接住，再考虑上调仓位。真正更强的安全边际仍在 `$80-$85` 附近。

## 公司概要

ServiceNow 是企业 workflow 平台，覆盖 IT、HR、客服、安全、风险、采购、现场服务、低代码和行业工作流。它的核心资产不是单个应用，而是大型企业内部的流程、权限、审批、CMDB、审计、服务目录和跨系统动作。AI 时代，如果企业让大量 agent 进入生产环境，就需要一个能控制“谁能做什么、基于什么数据、经过什么审批、留下什么记录”的执行层。ServiceNow 正在争夺这个位置。

商业模式以 subscription revenue 为主。FY2025 revenue 为 `$13.278B`，Q1 2026 total revenue 为 `$3.770B`，其中 subscription revenue 为 `$3.671B`。客户合同积压通过 RPO/cRPO 提供较强可见度。

ServiceNow 不按独立经营分部披露收入和利润，但产品组合大致覆盖 Technology Workflows、CRM and Industry Workflows、Core Business Workflows 和 Creator / Platform。投资者真正要判断的是：它能否从 ITSM 基地继续向安全、CRM、HR、行业工作流、低代码平台和 AI agent governance 扩张。

## 业务模式

ServiceNow 的价值可以拆成三层：

| 层级 | 主要内容 | 投资含义 |
|---|---|---|
| 核心 workflow 系统 | ITSM、ITOM、ITAM、Security Operations、Risk、HR、CSM、Field Service、Source-to-Pay | 迁移成本高，流程和数据模型深度嵌入 |
| 平台与数据层 | App Engine、Automation Engine、Workflow Data Fabric、RaptorDB Pro、Context Engine | 让 ServiceNow 从应用套件升级为企业运行时 |
| AI 执行与治理层 | Now Assist、AI Agents、Autonomous Workforce、AI Control Tower、Action Fabric、MCP Server | 让 AI agent 可以安全执行真实企业动作 |

最新产品叙事的重点是 **Action Fabric + AI Control Tower + Context Engine**。ServiceNow 试图把自己定位为“任何 AI agent 都可以调用的 system of action”：外部 agent 可以通过 MCP Server 触发 ServiceNow 里的流程、审批、playbooks 和业务规则；每次动作再经过 AI Control Tower 做身份验证、权限范围、审计、消耗计量和治理。

增长驱动包括：

1. 核心平台继续从 ITSM 向 ITOM、SecOps、Risk、HR、CSM、Field Service、Procurement、Creator workflow 扩展。
2. 企业 AI agent 需要权限、审计、流程、合规和异常处理，ServiceNow 的 bull case 是成为 AI agent 的 system of action。
3. Action Fabric / MCP Server 打开外部 agent 通道，Claude、Copilot 或客户自建 agent 可以调用受治理的企业动作。
4. Armis、Veza、Moveworks 分别补强资产安全、身份权限和企业搜索 / 对话入口。
5. 2030 年 subscription revenue `$30B+` 和 AI ACV 占比 `30%+` 是长期估值上移的核心路径。

## 竞争与护城河

护城河来源：

- **流程迁移成本**：ServiceNow 一旦嵌入 IT、HR、客服、安全、采购和审批流，迁移不是替换 UI，而是重做流程、权限、数据模型、集成和审计机制。
- **企业 workflow 数据优势**：AI agent 要执行真实动作，需要知道资产关系、服务依赖、权限和业务规则。ServiceNow 处在这些数据和流程的交汇处。
- **多产品扩张**：客户使用的模块越多，平台粘性越强，且 cross-sell 可持续提高 ACV。
- **企业级治理能力**：安全、合规、权限、人审、审计日志和大型企业采购能力，是通用 AI agent startup 难以短期复制的部分。
- **系统集成生态**：大型项目通常需要 Accenture、Deloitte、KPMG、Infosys 等 SI 生态落地，生态投入进一步提高替换成本。

## 估值分析

### 方法一：DCF

基准模型使用 10 年美债 `4.51%`、ERP `5.5%`、beta `0.927`，得到 WACC 约 `9.5%`。收入路径以 FY2026 revenue `$16.2B`、FY2027 `$19.2B`、FY2030 `~$28.2B` 为核心假设。

| 现金流口径 | 隐含价值 | 核心假设 |
|---|---:|---|
| 扣全额 SBC | `~$82` | SBC 完全视为普通股东真实成本 |
| 扣部分 SBC，基准 | `~$106` | FCFF margin `27.5% -> 31.5%`，承认 FCF 质量但不全按 non-GAAP |
| 公司 non-GAAP FCF | `~$124` | FCFF margin `35.0% -> 36.5%`，市场接受公司 FCF 口径 |

基准 DCF 敏感性：

| WACC \ g | 1.5% | 2.0% | 2.5% | 3.0% | 3.5% |
|---:|---:|---:|---:|---:|---:|
| 8.5% | `$110` | `$117` | `$125` | `$134` | `$145` |
| 9.0% | `$102` | `$108` | `$115` | `$122` | `$132` |
| 9.5% | `$95` | `$100` | `$106` | `$113` | `$120` |
| 10.0% | `$90` | `$94` | `$99` | `$104` | `$111` |
| 10.5% | `$84` | `$88` | `$92` | `$97` | `$103` |

### 方法二：相对估值

成熟应用软件同业 EV/Revenue 中位数约 `3.3x-3.4x`，但 NOW 的增长、订阅可见度和 AI execution layer 可选性明显高于这组。考虑到当前 NOW 本身交易在 `6.7x` TTM EV/Revenue，我采用 `6.5x FY2026E revenue` 和 `22x FY2027E EPS` 交叉验证。

| 估值口径 | 核心假设 | 隐含价值 |
|---|---:|---:|
| EV / FY2026E Revenue | `6.5x × $16.2B` | `~$104/股` |
| EV / FY2026E Revenue | `7.0x × $16.2B` | `~$112/股` |
| Forward P/E cross-check | `22x × FY2027E EPS $5.03`，折现一年 | `~$101/股` |
| 相对估值基准 | EV/Revenue 为主，P/E 交叉验证 | `~$104/股` |

### 方法三：SOTP

不做硬拆。ServiceNow 虽然有多条产品线，但并不按独立经营分部披露收入和利润，且经济实质是统一平台、统一客户关系和统一 go-to-market。把 ITSM、HR、CRM、安全和 AI 拆成多个独立资产套倍数，会制造虚假的精确性。

### 估值结论

| 情景 | 合理价值 | 核心假设 |
|---|---:|---|
| Bear | `~$60-$70` | organic growth 掉到 mid-teens 以下，AI 更多是防守而非增量，SBC / 并购继续压低现金流质量 |
| Base | `~$105` | FY2026 指引实现，Q2-Q3 organic cRPO 稳住，FY2027 margin normalization 逐步可见 |
| Bull | `~$160` | 2030 `$30B+` subscription revenue 路径可信，AI ACV 持续超预期，SBC 占收入下降，市场重新给予 AI workflow platform 溢价 |

当前 `$93.01` 已低于基准合理价值约 `11%-13%`，但高于扣全额 SBC 的保守价值。我的处理方式是：`$90-$95` 可以分批参与；`$80-$85` 以下才是更明显的安全边际；`$110+` 需要 Q2 / FY2027 margin 证据来支撑。

## 催化剂 / 关注点

**短期：**

- Q2 2026 财报：重点看 cRPO、subscription revenue、剔除 Armis 后的 organic growth、operating margin。
- Now Assist / AI Control Tower / Action Fabric 的 ACV、客户数、consumption revenue 是否有更清晰披露。
- Q2 non-GAAP operating margin 是否接近 `26.5%` 指引。
- FY2027 operating margin 和 FCF margin 是否恢复扩张。

**中期：**

- AI ACV 是否能向 2030 年 ACV `30%+` 路径推进。
- Action Fabric 是否能让外部 agent 成为 ServiceNow 的新增入口。
- AI Control Tower 是否能从治理工具变成高价值平台 SKU。
- SBC 占收入是否下降，回购是否只是抵消稀释还是提升每股价值。
- Armis、Veza、Moveworks 是否能形成安全 + 身份 + 企业搜索 + workflow 的平台协同。

## 风险 / 反向论证

1. **AI 收入披露不足**：已有 ACV 证据，但还不够连续，不能完全证明 AI 会推动长期 revenue acceleration。
2. **SBC 仍高**：Q1 2026 SBC 为 `$547M`，FY2025 SBC 为 `$1.955B`。如果市场严格扣 SBC，估值中枢会更接近 `$80-$90`。
3. **Armis 并购扰动 organic growth**：FY2026 指引包含约 `125 bps` Armis 贡献，且短期拖累 margin。
4. **AI 入口竞争**：Microsoft Copilot、Salesforce、Workday、Oracle、Atlassian、Palantir 以及模型厂商都在争夺企业 AI workflow 入口。
5. **股价技术面弱**：NOW 从 5 月底 `$124` 回落到 `$93`，说明市场仍未完全接受 AI 平台重估，需要财务验证重新建立信心。
6. **non-GAAP FCF 口径可能过于乐观**：如果把 SBC 当真实成本，non-GAAP FCF 模型会高估普通股东可得现金流。

**什么情况下我会撤回结论？**

如果未来两个季度剔除并购后的 cRPO constant currency growth 低于 mid-teens，且管理层不能给出 FY2027 margin 反弹的清晰路径，我会把观点从 `Watch / Accumulate Selectively` 下调到 `Pass`，估值中枢下调到 `$70-$85`。
