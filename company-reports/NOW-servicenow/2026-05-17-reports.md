# NOW - ServiceNow 研究报告

日期：2026-05-17

数据时间：行情与 yfinance 数据于 2026-05-17 JST 检查。股价使用 2026-05-15 美股 regular-session 收盘价。

## 核心结论

ServiceNow（`NOW`）是一家高质量企业软件公司，核心价值不是单点 IT 工单工具，而是嵌入大型企业 IT、HR、客服、安全、风险、采购和低代码应用的 workflow execution layer。AI 时代它的机会在于把模型输出接到权限、审批、记录系统、工单、CMDB 和合规留痕里，成为企业 AI agent 的受控执行层。

截至 2026-05-15 收盘，`NOW` 股价为 `$95.07`，市值约 `$98.0B`，企业价值约 `$95.3B`。我的基准估值约为 `$97/股`，其中 DCF 约 `$90`，相对估值约 `$104`。结论是：**公司质量强，当前价格已接近合理价值，但安全边际不厚**。更有吸引力的位置在 `$80-$85` 以下；如果 Q2/Q3 证明 organic cRPO 稳定、AI ACV 继续高增、SBC/收入开始下降，估值中枢可以上移。

本报告刻意采用保守口径：把 stock-based compensation（SBC）视为普通股东真实经济成本，而不是完全使用公司 non-GAAP free cash flow margin。若完全按公司 FCF 口径，估值会显著更高，但我认为那会低估长期稀释成本。

## 公司概要

ServiceNow 总部位于 Santa Clara, California，行业为 enterprise application software。公司提供云端 AI workflow 平台，帮助企业把跨部门请求、审批、工单、资产、权限、客户服务、HR 服务、风险与合规流程数字化和自动化。

商业模式以 subscription revenue 为主。云服务通常在合同期内按 ratable basis 确认收入，客户合同一般为固定金额、通常不可取消。2025 年总收入为 `$13.278B`，其中绝大部分来自 subscription。ServiceNow 的核心指标不是单个产品的市场份额，而是平台是否持续扩展到更多 workflow、更多部门和更高价值的 AI/安全/数据治理场景。

公司披露的 2026Q1 数据显示，订阅收入 `$3.671B`，同比增长 `22%`；总收入 `$3.770B`，同比增长 `22%`；cRPO 为 `$12.64B`，同比增长 `22.5%`；RPO 为 `$27.7B`，同比增长 `25%`。这些指标说明需求没有崩坏，但市场对 organic growth、并购贡献和 AI 对传统 SaaS 付费模型的影响仍有疑问。

## 业务模式

ServiceNow 的价值可以拆成三层：

| 层级               | 主要内容                                                                                                                                             | 投资含义                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 核心 workflow 系统 | ITSM、ITOM、ITAM、Security Operations、Integrated Risk Management、HR Service Delivery、Customer Service Management、Field Service、Source-to-Pay 等 | 嵌入流程、权限、数据模型和审计机制后迁移成本高   |
| 平台与低代码层     | App Engine、Automation Engine、Workflow Data Fabric、RaptorDB、Integration Hub、Creator / Developer tooling                                          | 从应用套件升级为企业内部 workflow app 平台       |
| AI 执行与治理层    | Now Assist、AI Agents、Autonomous Workforce、AI Control Tower、Context Engine、EmployeeWorks、Build Agent                                            | 把 AI 输出转化为可授权、可审计、可治理的企业动作 |

ServiceNow 不按独立经营分部披露收入和利润，但其产品组合大致覆盖 Technology Workflows、CRM and Industry Workflows、Core Business Workflows 和 Creator / Platform。对投资者来说，最重要的验证点是：公司能否从 ITSM 基地继续向安全、CRM、HR、行业工作流、低代码平台和 AI agent governance 扩张。

## Q1 2026 复盘

Q1 2026 财报是 headline beat-and-raise，但股价没有按传统高质量 SaaS beat-and-raise 反应。原因主要是市场拆解了增长质量和利润率路径。

## 增长驱动

1. **核心平台继续扩张**：ServiceNow 从 ITSM 向 ITOM、SecOps、Risk、HR、CSM、Field Service、Procurement、Creator workflow 扩展，模块越多，切换成本越高。
2. **AI agent 治理需求上升**：企业部署 AI agent 后需要权限、审计、流程、合规和异常处理。ServiceNow 的 bull case 是成为 AI agent 的 system of action，而不是被 AI 抽象层绕过。
3. **安全与身份能力补强**：Armis、Veza 和 Moveworks 分别补强资产安全、身份权限和企业搜索/对话入口，有助于把 ServiceNow 从 workflow 平台扩展成更完整的 AI execution and governance stack。
4. **2030 长期目标**：公司在 2026 年 Financial Analyst Day 提出 2030 年 subscription revenue `$30B+` 目标，并预计 ServiceNow AI 到 2030 年占 ACV 超过 `30%`。这相当于从 2026 指引中点起维持约 high-teens 复合增长。

## 竞争与护城河

**护城河来源：**

- **流程迁移成本**：ServiceNow 一旦嵌入 IT、HR、客服、安全、采购和审批流，迁移不是替换 UI，而是重做流程、权限、数据模型、集成和审计机制。
- **企业 workflow 数据优势**：AI agent 要执行真实动作，需要知道资产关系、服务依赖、权限和业务规则。ServiceNow 处在这些数据和流程的交汇处。
- **多产品扩张**：客户使用的模块越多，平台粘性越强，且 cross-sell 可持续提高 ACV。
- **企业级治理能力**：安全、合规、权限、人审、审计日志和大型企业采购能力，是通用 AI agent startup 难以短期复制的部分。
- **系统集成生态**：大型项目通常需要 Accenture、Deloitte、KPMG、Infosys 等 SI 生态落地，生态投入进一步提高替换成本。

## 估值分析

### 方法一：SBC-adjusted DCF

基准模型把 SBC 视为真实经济成本。核心假设如下：

| 假设                   |                                        基准值 |
| ---------------------- | --------------------------------------------: |
| FY2026 revenue         |                                    `$16.2B` |
| FY2027 revenue         |                                    `$19.2B` |
| FY2030 revenue         |                                    `$28.2B` |
| 2026-2030 revenue path | `22.0% -> 18.5% -> 16.0% -> 13.5% -> 11.5%` |
| Owner FCFF margin      |                            `19.5% -> 24.5%` |
| WACC                   |                                      `9.0%` |
| Terminal growth        |                                      `2.5%` |
| 净现金                 |                                   `~$2.75B` |

基准 DCF 约为 **`$90/股`**。这个结果低于公司口径 FCF 推导，因为模型没有把 SBC 完全视为免费融资。

### 方法二：相对估值

ServiceNow 当前约 `6.8x` TTM EV/Revenue。成熟应用软件同业（CRM、WDAY、ADBE、INTU、SAP）大多在 `3x-6x` EV/Revenue；更高增长的基础设施/安全/数据类 SaaS 可以明显更高。考虑 NOW 增速高于成熟应用软件、但低于 hypergrowth SaaS，同时利润率和 FCF 质量强于多数高增长 SaaS，我采用约 `6.5x` FY2026E EV/Revenue 作为基准。

| 估值口径                |                                               核心假设 |     隐含价值 |
| ----------------------- | -----------------------------------------------------: | -----------: |
| EV / FY2026E Revenue    |     `6.5x` FY2026E revenue `$16.2B` | `~$105/股` |              |
| Forward P/E cross-check | `22x` FY2027E EPS `$5.03`，折现一年 | `~$101/股` |              |
| 相对估值基准            |                          EV/Revenue 为主，P/E 交叉验证 | `~$104/股` |

### 方法三：SOTP

不做硬拆。ServiceNow 虽然有多条产品线，但并不按独立经营分部披露收入和利润，且经济实质是统一平台、统一客户关系和统一 go-to-market。把 ITSM、HR、CRM、安全和 AI 拆成多个独立资产套倍数，会制造虚假的精确性。

### 估值结论

| 情景 |       合理价值 | 核心假设                                                                                                                |
| ---- | -------------: | ----------------------------------------------------------------------------------------------------------------------- |
| Bear |    `$55-$70` | Organic growth 掉到 mid-teens 以下，AI 更多是防守而非增量，SBC / 并购继续压低现金流质量                                 |
| Base |   `$90-$105` | FY2026 指引实现，Q2-Q3 organic cRPO 稳住，FY2027 margin normalization 逐步可见                                          |
| Bull | `$130-$150+` | 2030 `$30B+` subscription revenue 路径可信，AI ACV 持续超预期，SBC 占收入下降，市场重新给予 AI workflow platform 溢价 |

当前 `$95.07` 基本在基准合理价值附近。我的点估值为 `$97`，因此不是明显高估，也不是典型深度价值机会。

## 催化剂 / 关注点

**短期（< 6 月）：**

- Q2 2026 财报：重点看 cRPO、subscription revenue、剔除 Armis 后的 organic growth、operating margin。
- Armis / Veza / Moveworks 整合：是否形成 cross-sell，还是继续压低利润率。
- AI 产品披露：Now Assist / AI Control Tower / Autonomous Workforce 的 ACV、客户数和大型 deal 数。
- EPS 修正：当前 FY2026 EPS consensus 为 `$4.12`，FY2027 为 `$5.03`。如果继续下修，估值会承压。

**中期（6-18 月）：**

- FY2027 margin normalization 是否兑现。
- AI ACV 是否能向 2030 年超过 30% ACV 的目标推进。
- Subscription revenue growth 能否在不靠大额并购的情况下维持 high-teens 到 20%。
- SBC 占收入是否开始下降，回购是否只是抵消稀释，还是能够真正提升每股价值。

## 风险 / 反向论证

1. **Organic growth 低于 headline**：如果剔除 Armis 后 cRPO/订阅收入持续放缓，`6.8x` EV/Revenue 仍可能被压到 `5x` 或更低。
2. **SBC 和稀释**：FY2025 SBC 为 `$1.955B`，Q1 2026 SBC 为 `$547M`。公司回购能管理稀释，但若用股东真实经济成本衡量，FCF 质量要打折。
3. **AI 竞争改变定价**：Microsoft、Salesforce、Oracle、SAP、Workday、Atlassian，以及 AI agent 初创公司都在争夺企业工作流入口。ServiceNow 必须证明 agentic workflow 是增量，而不是被 AI 抽象层绕过。
4. **并购整合风险**：Armis、Veza、Moveworks 分别进入资产安全、身份权限和企业搜索 / 对话入口，战略上相关，但整合复杂，短期 margin headwind 已经明确。
5. **大型企业销售周期和地缘风险**：Q1 2026 订阅收入增长受到中东大型 on-prem deal 延迟约 75 bps 拖累；大型交易集中在季度末，容易造成 cRPO 波动。

**什么情况下我会撤回结论？**

如果未来两个季度剔除并购后的 cRPO constant currency growth 低于 mid-teens，且管理层不能给出 FY2027 margin 反弹的清晰路径，我会把观点从 `Watch` 下调到 `Pass`，估值中枢下调到 `$70-$85`。

## 管理层与资本配置

- **CEO / CFO**：Bill McDermott 任 Chairman & CEO；Gina Mastantuono 任 President & CFO。
- **回购**：Q1 2026 公司回购约 20.1M 股，其中包括此前 `$2B` ASR 的 18.5M 股，以及公开市场回购 1.6M 股、金额 `$225M`。截至 Q1 末，回购授权剩余约 `$4.2B`。
- **并购**：2026 年 Q1 关闭 Veza；2026-04-20 关闭 Armis；2025 年已关闭 Moveworks。资本配置重点明显转向 AI / security / identity / enterprise search 的平台补强。

## 后续关键问题

1. 剔除 Armis 后，Q2 2026 cRPO constant currency growth 是继续放缓还是稳定？
2. Now Assist / AI Control Tower / Autonomous Workforce 的 ACV 是否能继续高增长，并转化为实际 revenue acceleration？
3. FY2027 operating margin 和 FCF margin 是否如管理层所说恢复扩张轨迹？
4. SBC 占收入是否开始下降，还是仍需大规模回购对冲稀释？
5. Armis、Veza、Moveworks 是否能形成安全 + 身份 + 企业搜索 + workflow 的平台协同，而不是并购组合摊薄？
6. AI agent 会强化 ServiceNow 的 system-of-action 位置，还是把用户入口抽象到 Microsoft Copilot、Salesforce、Atlassian 或其他 agent layer？
