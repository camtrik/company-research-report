Healthcare · 医療用電子機器

日本光电以患者监护仪、脑波計 (EEG)、心電図 (ECG)、除細動器为核心产品， 国内监护市场份额领先（多年保持龙头），同时通过血液诊断、CathLab 设备、医院信息系统等切入诊断与重症监护场景。 海外业务占比近年提升至约 30%+，覆盖北美、欧洲、亚洲、拉美。 商业模式 = "设备销售 + 耗材/服务"，长尾耗材（电极、纸张、导线、维护合约）提供稳定毛利底盘， 毛利率长期维持在 50% 上下。

护城河来源（速览）

  • 日本院内监护装机量长期领先，电子病历集成形成切换成本
  • 耗材 / 服务 / 维护合约的 recurring 现金流，构成稳定 50% 毛利底盘
  • 行业监管壁垒（PMDA、JCI、FDA、CE）+ 临床验证周期长
  • 强资产负债表（净现金 ¥17B、自有资本比率 70% 左右）支撑研发与海外扩张
公司不披露独立分部报表，收入结构来自年报描述性披露。海外业务占比约 30%+。

核心结论

观点 · Watch · 基准合理价值 ¥1,830

当前 ¥1,503.5 接近 52 周低点 ¥1,408， 估值已隐含了"利润率永远回不去"的悲观情景。 基准合理价值 ¥1,830（DCF ¥1,627 与同业相对估值 ¥2,040 的 50/50 混合）， 对应约 +22% 上行，与卖方 8 人共识目标价中位 ¥1,880 一致。

核心看多点是患者监护设备需求修复 + 强资产负债表（净现金 ¥17B）+ 22% 折价 vs 同业 + 治理改善预期。

核心反向风险是 OPM 自 FY22 的 15% 一路滑落到 9%，ROE 只 8%，海外竞争加剧。 安全边际：Bear case ¥1,280 与 52 周低点 ¥1,408 接近，意味着下行风险已被部分消化。 利润率能否回到 11%+ 是估值最大单一变量。

业务模式

日本光电的收入来源围绕四大产品线，设备销售带动后续 5–10 年的耗材 + 服务 + 维护合约：

  • 01
    生体情報モニタ（患者监护仪） — 最大单一品类，日本行业领先份额。
  • 02
    検査機器 — EEG / 心电 / 多导生理记录仪。
  • 03
    治療機器 — 自动体外除颤器 AED、CathLab、心律失常治疗设备。
  • 04
    其他 — 信息系统、耗材、服务、海外 OEM。

现金流引擎

设备销售带动后续 5–10 年的耗材 + 服务 + 校正/维护合约（recurring，毛利 60%+）。 这是公司在低收入增长下仍能维持稳定 EBITDA 的基础。

公司不披露独立分部报表，收入结构来自年报描述性披露。海外护城河较弱（直面 Masimo、GE Healthcare、Philips、Mindray）。

主要风险

按可能性 × 影响排序

01. 利润率结构性下沉

FY25 的 OPM 9% 是新常态而非周期低点。若毛利率 51% 因竞争或材料成本失守，DCF 公允价对应再下挫 ¥200–¥300。监控信号：季度毛利率连续 2 季 < 50%。

02. 海外竞争与 FX

Masimo / GE / Philips / Mindray 在监护与诊断领域价格战，叠加日元升值 → 海外营收和利润双杀。监控信号：海外营收占比下滑 + 日元 < ¥140/USD。

03. 资本配置 / ROE 锁死

现金不分配、不回购、不并购，市场会继续给 1.4x P/B（治理折价）。监控信号：年度资本回报政策无更新。

04. 国内监护设备替换周期延后

日本医院预算紧缩 / 医保收紧推迟换机。监控信号：日本国内监护品类增长 < 2%。

05. 数据质量

本报告 yfinance β 为空（用 0.80 默认值）、Diluted EPS FY25 缺失、ΔNWC 波动极大；最终结论应以 EDINET / 公司有価証券報告書一手核对。

撤回条件

OPM 连续 2 季跌破 8%，或毛利率连续 2 季跌破 50% → 利润结构性恶化，撤回正面观点。 股价站上 ¥1,900（接近基准合理价上沿）且 OPM 未修复至 10%+ → 估值已透支催化剂，下调至 Pass。
