Technology · Semiconductor IP

ARM 总部位于 Cambridge, UK，上市证券为 Nasdaq ADR。公司不直接大规模制造芯片，而是设计和授权处理器架构、 CPU 核、GPU、NPU、interconnect、compute subsystem 和相关软件生态。客户包括手机 SoC 厂商、车载芯片厂商、 IoT/工业厂商、cloud hyperscalers、AI accelerator 厂商和数据中心系统供应链。

护城河来源（速览）

  • 生态标准：OS、编译器、EDA、IP、foundry、开发者围绕 Arm 架构形成长期兼容性优势
  • 能效优势：移动时代积累的低功耗设计，在数据中心和 AI inference / orchestration 更有价值
  • Royalty 复利模型：客户采用后多年出货带来持续 royalty；Armv9 / CSS / Neoverse 提高单芯片 royalty dollars
  • AI compute position：agentic AI 需要更多 CPU coordination，ARM 可受益于每 AI rack 中 CPU 数量和价值量提升
ARM 的护城河本质是生态和兼容性：架构已嵌入移动、车载、IoT、PC 和云端 CPU 生态，开发者、操作系统、编译器、 EDA、IP、Foundry 和系统厂商共同形成平台网络效应。

核心结论

观点 · Watch · 基准合理价值 ~$200 · 不追涨

ARM 是全球最重要的处理器 IP 平台之一。2026 年以来，投资者开始把它重新定价为 AI data center CPU、 hyperscaler custom silicon 和 agentic AI infrastructure 的 royalty layer。

截至 2026-05-21 收盘，股价 $298.23，市值约 $317.3B。 5 月 20–21 日两日累计上涨约 33.7%。保守 DCF 很难支持 $298； 相对估值需要 FY2027E 45–55x EV/Revenue 或 90–110x EPS 才接近现价。

ARM 是高质量资产，但当前价格已经在交易非常乐观的长期剧本，缺乏安全边际。

直接催化是 NVIDIA Vera / Rubin CPU 叙事、NVIDIA 超预期财报、Jefferies / Bernstein / RBC 等 sell-side 上调目标价，以及 ARM 自身 FY2026 Q4 强劲财报共同形成的动量重估。 持有者可以继续用趋势和基本面验证管理仓位；新资金需要等待回撤或更明确的 AGI CPU 收入兑现。

业务模式

ARM 的业务可以拆成四层，互相支撑：

  • 01
    Architecture — Arm instruction set / Armv9 等架构授权。最底层标准，客户粘性高，但 royalty rate 取决于合同结构。
  • 02
    IP Cores — Cortex、Neoverse、Mali、Ethos 等 CPU/GPU/NPU/IP。传统主业，覆盖移动、车载、IoT、数据中心。
  • 03
    CSS / Platform — Neoverse CSS、compute subsystem、预集成平台。提升客户采用速度和 ASP，有助于提高 royalty dollars per chip。
  • 04
    Silicon / AGI CPU — ARM 自身推出面向 agentic AI 的 production silicon。新增长向量，但也可能改变原有轻资产模型和客户关系。

主要风险

按可能性 × 影响排序

01. 估值前置过多

当前约 64x FY2026 revenue 和 168x FY2026 non-GAAP EPS，已经折现了多年高增长和高倍数，任何下修都可能导致大幅回撤。

02. AGI CPU 收入不确定

自研 silicon 是新方向，可能带来更高收入，但也可能带来更高研发/供应链/客户冲突风险，削弱原有轻资产 IP 模型。

03. Royalty rate 与出货量不透明

NVIDIA Vera 或 hyperscaler CPU 的总销售额不等于 ARM 收入，关键取决于 royalty rate、合同结构和确认节奏。

04. SBC 稀释

FY2026 SBC $1.052B，占收入 21.4%。如果把 SBC 当真实成本，现金流质量比 non-GAAP 利润看起来弱。

05. 智能手机仍是重要基础盘

若高端手机换机、Android SoC 或中国智能手机链条疲软，可能拖累 royalty growth。

06. 客户集中与生态冲突 / SoftBank 控制权

Apple、Qualcomm、NVIDIA、hyperscalers 都有强议价能力；ARM 若向 silicon 延伸可能改变与部分 licensees 的关系。 SoftBank 仍是重要控股股东，其资本配置和潜在减持会影响少数股东风险收益。

撤回条件

如果未来两个季度数据中心 royalty 没有明显加速，Q1/Q2 FY2027 指引或实际收入低于预期， 且 FY2028 AGI CPU / Vera / hyperscaler CPU 相关收入没有被 consensus 实质性上修， 会把观点从 Watch 下调到 Pass，并把合理价值中枢下调到 $120 – $170。
