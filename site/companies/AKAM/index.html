Technology · Software Infrastructure

Akamai 起家于 CDN 和边缘网络，核心资产是全球分布式网络、客户流量入口、应用交付能力和安全防护能力。 公司 2026 年起把业务单独披露为三类：Security（WAF / API security / DDoS / bot / Guardicore 微分段 / ZTNA 等）、 Delivery and other cloud applications（传统媒体交付、应用性能、边缘应用），以及 Cloud Infrastructure Services （compute、storage、EdgeWorkers，当前主要投资和资本开支方向）。

核心结论

观点 · Watch · 基准合理价值 ~$120

Akamai 的估值已经从传统 CDN / 安全软件公司，转向“安全现金流 + 衰退中的 Delivery + 高资本开支 AI/CIS 云基础设施”的组合。 基准混合合理价值约 $120/股，对比当前股价 $120.74 基本持平，当前不是明显低估。

DCF 约 $103/股（被 2026 年高 CapEx、SBC 和 CIS 前置投入压低），相对估值约 $129/股，SOTP 约 $134/股 （公司未披露分部 EBITDA，仅作低置信度交叉验证）。

更适合观察或已有仓位持有，而不是当成有明显安全边际的价值股。

真正的上行来自 CIS 大单持续复制、2027 年后收入进入双位数增长、CapEx 强度回落； 反向风险是 CIS 需要持续烧 CapEx，ROIC 尚未被验证。

业务模式

三类业务，分别处于增长、衰退、重资本投入三个阶段：

  • 01
    Security — 当前最像优质软件资产的部分。Q1 2026 收入 $590M（+11%），需求来自 WAF、API security、Guardicore 分段等；AI 提升攻击自动化，强化企业防护刚需。
  • 02
    Delivery and Other Cloud Applications — 传统现金流基础，但结构性承压。Q1 2026 收入 $389M（-7%），续约降价 + 客户成本优化驱动下滑。
  • 03
    Cloud Infrastructure Services — 投资争议核心。Q1 2026 收入 $95M（+40%），FY2026 constant-currency 增长指引上调到至少 50%，但需要重资本开支支持。

业务分部风险 / 机会拆解

业务优点风险
Security客户需求紧迫，毛利和估值倍数通常高于 Delivery需与 Cloudflare、Palo Alto、Fortinet、Zscaler、CrowdStrike、Check Point 竞争，并非全部收入都享受纯 SaaS 高倍数

CIS 是“收入可见度提升”和“短期 FCF 大幅承压”同时发生的业务：管理层 Q1 call 给出 FY2026 CapEx 约 40%-42% revenue （其中约 $700M 与 $1.8B 大客户合同相关），Q2 CapEx 指引约 $433M-$453M。

护城河

护城河评级：Distribution Network + Switching Cost, Eroding at the Edges。核心来源：

全球分布式网络规模

平台覆盖约 4,300 locations、700 cities、130 countries，可在靠近用户处提供交付、安全和 compute。

安全数据与流量入口

在应用、API、bot、DDoS 和 WAF 场景积累大量实时流量和攻击数据，提升检测和防护能力。

大客户关系与迁移成本

媒体、金融、零售、游戏和技术公司长期使用 Akamai 网络和安全服务，迁移成本不低。

CIS 的差异化位置

不与 hyperscaler 做全栈云正面对抗，而是押注 distributed compute、edge inference 和 dedicated capacity。

近期动态

最近财报（Q1 2026）

Q1 2026 收入 $1.074B，同比 +6%（constant currency +4%）。GAAP operating income $114M、GAAP operating margin 11% （同比下降 4 个百分点），non-GAAP operating margin 26%。

分业务看，Security 增长 11%、CIS 增长 40%、Delivery and other cloud applications 下降 7%。 这就是当前投资故事的核心：增长资产在变大，但成熟现金流业务和利润率同时承压。

2026-05 可转债融资

2026-05-22，Akamai 完成 $3.5B 0.00% convertible senior notes 发行，2030 notes 与 2032 notes 各 $1.75B。 公司用约 $236.6M 支付 convertible note hedge 净成本，约 $350M 回购 2,476,298 股，剩余资金主要用于 CIS 加速资本开支和一般公司用途。

2030 notes 初始转换价约 $201.41，2032 notes 约 $190.81。在当前股价 $120.74 下短期稀释不明显； 但若 bull case 兑现，转换和 warrant 结构会影响高股价区间的普通股价值。

  • 2026 Q1　公司宣布美国 frontier model provider 对 CIS 做出 $1.8B / 7 年 committed deal，史上最大客户合同。CIS 增长可见度的关键锚点。

主要风险

按可能性 × 影响排序

01. CIS ROIC 尚未验证

公司已承诺重资本开支，收入有可见度，但长期毛利和现金回报还需要验证。

02. CapEx 可能继续上修

管理层表示 GPU pipeline 超过当前和预计库存，若 2026 下半年继续下单，FCF 压力会加大。

03. Delivery 结构性下滑

续约价格下降和客户成本优化仍可能拖累整体收入增速。

04. 估值被 AI 叙事提前重估

过去 12 个月股价已上涨约 52%，当前价格已经部分反映 CIS 大单价值。

05. SBC 是真实成本

TTM SBC 约 $476M，若投资者严格扣除 SBC，owner earnings 低于非 GAAP 利润。

06. 可转债和 warrants 增加复杂度

当前转换价较高，短期稀释有限；但 bull case 中会影响每股价值。

07. 竞争强度高

CIS 面对 hyperscalers、neoclouds 和 GPU capacity providers；Security 面对 Cloudflare、Palo Alto、Fortinet、Zscaler、CrowdStrike 等，定价和份额持续承压。

撤回条件

如果 FY2026 下半年 CapEx 再次明显上修，而 CIS revenue ramp 或新增合同没有同步兑现，应下调估值中枢。 若 Delivery 下滑扩大到 high-single-digit 以上，同时 Security 增速跌破 mid-single-digit，则 AKAM 的转型故事会变成更高风险的资本开支押注。
